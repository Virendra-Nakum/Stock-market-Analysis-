# Stock Market Data Analysis & Visualization

### A Python-Based Project for Stock Market Analysis, Statistical Operations, and Data Visualization

## 📌 Project Overview

The **Stock Market Data Analysis & Visualization** project is a Python-based application that analyzes stock market datasets using Pandas, NumPy, Matplotlib, and Seaborn.

It provides a menu-driven interface to load CSV files, explore datasets, clean data, perform stock market analysis, generate visualizations, and display analytical reports.

## 🚀 Features

### 1. Load Dataset
- Load stock market data from CSV files.
- Handle invalid file paths.

### 2. Explore Dataset
- Display first and last five rows.
- Display column names.
- Check data types.
- Display dataset information.
- Generate statistical summaries.

### 3. Clean Dataset
- Check missing values.
- Handle missing values.
- Remove duplicate records.
- Convert date columns.
- Check invalid stock prices.

### 4. Data Analysis
- Calculate daily stock returns.
- Calculate average stock prices.
- Find highest and lowest stock prices.
- Calculate stock volatility.
- Analyze trading volume.
- Calculate 7-day moving averages.
- Analyze daily price changes.

### 5. Data Visualization
Generate six different visualizations:

- Stock Price Line Chart
- Trading Volume Bar Chart
- Moving Average Chart
- Daily Returns Histogram
- Stock Price Area Chart
- Correlation Heatmap

### 6. Analysis Results
- Display overall stock summary.
- Analyze stock performance.
- Perform risk analysis.
- Analyze stock price trends.
- Generate a final stock report.

## ⚙️ Installation

**Step 1: Install Python**

Download Python from:

https://www.python.org/downloads/

**Step 2: Install Required Libraries**

Open the terminal and run:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

**Step 3: Run the Project**

Open Jupyter Notebook:

```bash
jupyter notebook
```

Open `main.ipynb` and run the notebook cells.

## 📊 How to Use

1. Run the notebook.
2. Enter the CSV dataset path.
3. Explore the dataset.
4. Clean missing and duplicate values.
5. Select a stock analysis operation.
6. Generate stock market visualizations.
7. View the final analytical report.

**Note:** If the dataset contains multiple companies, select or filter a particular stock using its `Symbol` before performing stock-specific analysis.
